# Сайт Полины

Учебник и практика русского языка для учеников Полины, готовящихся к ОГЭ/ЕГЭ.

Репозиторий: https://github.com/RudySimp/polina-russian-site.
Публикация: https://rudysimp.github.io/polina-russian-site/. Подтверждение релиза — в [статусе](docs/СТАТУС_РАЗРАБОТКИ.md).

## Запуск в Windows

Node.js 24 LTS установлен переносимо в игнорируемой .tools. Рабочая папка: `C:\Users\musor\Desktop\Сайт Полины`.

```powershell
Set-Location -LiteralPath 'C:\Users\musor\Desktop\Сайт Полины'
.\scripts\windows.ps1 showcase:dev
```

Адрес: http://127.0.0.1:4173/polina-russian-site/. Он открывается только на этом компьютере при запущенном процессе. Остановка Ctrl+C.

На машине с Node в PATH: `npm ci`, затем `npm run showcase:dev`.

## Две части

- `apps/showcase`: статическая витрина Vite/React. 16 полноценных уроков и 252 задания: ОГЭ 222 (по 20 в каждой линии 2–12 и два прежних учебных упражнения), ЕГЭ 30. ОГЭ включает банк с решением на странице, подборки 5/10/20/все, пять полных вариантов с аудио и письменными черновиками, воспроизводимый генератор, семь тематических тренажёров и локальные результаты. Аккаунтов и передачи результатов Полине нет.
- `src/app`, `src/db`, `drizzle`: сохранённый Next.js 16 API и PostgreSQL 17. Сессии, роли, назначения, снимки версий, попытки и уведомления. Пользовательские кабинеты ещё не реализованы. Эта часть не публикуется в Pages.

## Проверки

```sh
npm ci
npm run typecheck
npm run showcase:typecheck
npm run lint
npm test
npm run build
npm run showcase:build
npm run test:e2e
```

В Windows команды запускаются через `.\scripts\windows.ps1 <имя-скрипта>`. Браузерные тесты используют установленный Chrome; на CI устанавливается Chromium. Для Linux: `npx playwright install --with-deps chromium`. Для публичного сайта задайте PUBLIC_URL=https://rudysimp.github.io/polina-russian-site/ перед тестами.

Workflow `.github/workflows/deploy-pages.yml`: проверки обеих частей, браузерные сценарии и публикация только `apps/showcase/dist` при push в main. PR проверяется без деплоя. Статические маршруты и ассеты используют /polina-russian-site/; неизвестный маршрут показывает ошибку.

## Backend

```sh
npm run setup:env
npm run db:up
npm run db:migrate
npm run seed
npm run dev
node scripts/check-environment.mjs
```

Нужен PostgreSQL 17 (Docker Compose либо локальная база). Секреты только в .env; демопароли генерируются в игнорируемой .local/demo-credentials.json. Seed сохраняет существующие записи. Без сессии API возвращает 401. GitHub Pages API и БД не запускает.
