# Добавление материалов

1. Оригинальный пример или подтверждённые права. Закрытые материалы — private-materials до разрешения публикации.
2. Тема, навык, объяснение, ошибка, шаги, источник, год, редакторский статус. Утверждение Полины не приписывается без проверки.
3. Разделяйте теоретические игры и экзаменационную практику. Укажите прочитанную спецификацию и статус.
4. При изменении критериев увеличьте revision. Не изменяйте snapshots старых назначений.
5. Typecheck обеих частей, lint, unit, обе сборки, test:e2e.
6. Проверьте diff на секреты/персональные данные; обычный commit/push, затем Actions и публичный URL.
