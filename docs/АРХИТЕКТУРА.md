# Архитектура

Публичная часть — apps/showcase, Vite/React. Экспортируется HTML каждого известного маршрута из src/routes.ts; ресурсы используют /polina-russian-site/. Шрифты системные, внешних изображений и API нет. Markdown подгружается при открытии урока.

Теория — сохранённые src/db/demo.ts, без импорта БД. Оригинальные задачи — content.ts. Общий движок src/lib/grading.ts проверяет ответы обеих частей. progress.ts хранит до 200 попыток в браузере, проверяет формат и пересчитывает оценки при чтении.

Сохранён backend Next.js 16.4/PostgreSQL 17/Drizzle/Argon2 из коммита fb4aca5. Добавлены layout и служебная главная. API остаётся динамическим; output: export не включается. Код БД/сессий не импортируется витриной.

Кабинеты и серверное размещение — следующие этапы. Авторизация через localStorage отсутствует. Статическая история не является защищённым журналом.
