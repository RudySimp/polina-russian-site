# Развёртывание

Основная папка: C:\Users\musor\Desktop\Сайт Полины. Переносимые Node 24 LTS и gh находятся в игнорируемой .tools. scripts/windows.ps1 добавляет Node в PATH текущего процесса.

Демо: .\scripts\windows.ps1 showcase:dev → http://127.0.0.1:4173/polina-russian-site/.
Backend: .\scripts\windows.ps1 dev → http://localhost:3000. Остановка Ctrl+C.

Remote https://github.com/RudySimp/polina-russian-site.git, main. Source Pages=GitHub Actions. deploy-pages.yml проверяет обе части и публикует только dist витрины. PR без публикации.

Обновление: проверки → diff/новые файлы → обычный commit/push → Actions → URL, вложенные маршруты, ассеты и клики. Force push запрещён.

scripts/github.ps1 передаёт GCM credentials через GH_TOKEN только в памяти, не пишет и не выводит токен. При отсутствии доступа используйте gh auth login.

Pages не запускает API/PostgreSQL. Внешние/платные ресурсы не создавались; серверное размещение требует согласования. compose.yaml, миграция и seed сохранены.
