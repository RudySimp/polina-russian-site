# Ближайшие этапы

1. Подтверждённый релиз: зелёный Actions, HTTP 200, маршруты/ассеты/интерактив.
2. Официальные PDF 2026/проекты 2027: форматы, номера, рубрики, статус — без перепубликации.
3. Локальная PostgreSQL 17: миграции, идемпотентный seed, сессии, изоляция, назначение/сдача/версии.
4. Авторские материалы Полины и защищённые кабинеты: импорт, редактор, назначения, аналитика.
5. Согласование хостинга, расходов, обработки данных и каналов уведомлений; приёмка безопасности и резервного копирования.

Публичная витрина публикуется до расширения backend. Этапы не объявляются готовыми без проверки.
