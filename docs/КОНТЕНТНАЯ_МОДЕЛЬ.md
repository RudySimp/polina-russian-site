# Контентная модель

Направление → раздел → тема → правило → пример → практика → ошибка → повторение.

Три демотемы: орфоэпия, НЕ с качественными прилагательными, однородные члены. content.ts содержит topicSlug, skillId, misconceptionId, pairId, шаги и объяснения вариантов. Метаданные источника включают тип/URL, автора, права, год, дату проверки, редакторский статус. Демо имеет needs_review.

Политика каждой задачи определяет регистр, пробелы, Ё/Е, порядок цифр, разделители, длину, допустимые эталоны. В публичной экзаменационной практике порядок цифр несущественен; разделители и повторы запрещены. Ошибки формата исправляются до записи попытки.

Backend хранит content_revisions и assignment_items.snapshot: последующее редактирование не меняет старые результаты. При изменении критериев увеличьте revision. Номера задач и официальные баллы не задаются без проверки конкретной спецификации.
