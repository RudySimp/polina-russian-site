# Домашние задания

Публичная версия — самостоятельная тренировка без назначений и передачи результатов преподавателю.

Сохранённый API поддерживает принадлежность учеников, назначение, снимки задач, версионный черновик, атомарную сдачу, проверку кратких ответов и уведомление о сдаче. Повторная сдача не создаёт новую попытку. Доступ фильтруется по владельцу.

Не реализованы кабинеты, лимиты попыток, полная просрочка и рубрика сочинений. feedbackMode=manual задерживает автоматический разбор, но не реализует ручную проверку развёрнутого ответа.

Приёмка: назначить своему ученику → увидеть только своё → сохранить → сдать → получить разрешённый разбор → показать реальный результат преподавателю. Проверить чужие ID, конфликт вкладок, повторную сдачу и версии.
