Публичные задачи оригинальные, краткий ответ — номера вариантов. Номера экзаменационных задач и баллы без отдельной проверки не приписываются. Игры по теории отдельно обозначены.

Срок окончания обсуждения не доказывает утверждение. Нужна проверка конкретного PDF/версии и Полины. Чтение страниц не заменяет проверку всех официальных документов.

Исследуемые PDF — только в игнорируемой private-materials, без перепубликации. Условия повторного использования конкретных документов пока не подтверждены; внешний контент в сборку не включён.
