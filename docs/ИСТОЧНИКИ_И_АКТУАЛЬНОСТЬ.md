# Проверка источников

Дата: 10 октября 2026 года. Повторная проверка после сообщения пользователя об изменении сетевой политики.

| Домен | DNS на машине | curl exit | HTTP целевой страницы | Ответ прокси на CONNECT | TLS с сайтом |
| --- | --- | --- | --- | --- | --- |
| fipi.ru | Temporary failure in name resolution | 56 | 000 | 403 Forbidden | Не начат |
| doc.fipi.ru | Temporary failure in name resolution | 56 | 000 | 403 Forbidden | Не начат |
| rus-ege.sdamgia.ru | Temporary failure in name resolution | 56 | 000 | 403 Forbidden | Не начат |
| rus-oge.sdamgia.ru | Temporary failure in name resolution | 56 | 000 | 403 Forbidden | Не начат |

Команда для каждого домена: `curl --silent --show-error --location --verbose --connect-timeout 10 --max-time 25 --output /tmp/page.html --write-out 'http=%{http_code} connect=%{http_connect} ssl_verify=%{ssl_verify_result}\n' https://DOMAIN/`.

Точная ошибка: `curl: (56) CONNECT tunnel failed, response 403`. Отказ происходит при создании HTTPS-туннеля через инфраструктурный прокси, до обмена TLS с целевым сайтом. Значение `ssl_verify_result=0` здесь не доказывает корректность сертификата: TLS-проверка не выполнялась. HTTP 403 принадлежит прокси, его нельзя приписывать ФИПИ или «Решу». Невозможность прямого DNS-разрешения не доказывает неработоспособность публичного DNS домена.

Доступный инструмент чтения конфигурации после повторной проверки всё ещё показывал `restricted` с набором `package_managers`. Применение заявленного изменения к текущей машине не подтверждено. Обход прокси, отключение TLS-проверки и изменение сетевой политики не выполнялись.

## Статус методических сведений

Страницы ФИПИ по ЕГЭ и ОГЭ также недоступны через этот прокси:

- https://fipi.ru/ege/demoversii-specifikacii-kodifikatory
- https://fipi.ru/oge/demoversii-specifikacii-kodifikatory

Документы 2027 года не прочитаны; наличие, проектный/окончательный статус, номера заданий, шкалы и критерии не подтверждены. Записи версий ОГЭ/ЕГЭ 2027 в БД имеют статус `draft`, `verifiedAt=null`. Демоупражнения проверяют отдельные языковые навыки и не объявляются заданиями официальной экзаменационной модели. Их баллы — техническая метрика, а не баллы ФИПИ.

Материалы «Решу ЕГЭ/ОГЭ» не скачивались и не копировались. Эти сайты предназначены только для будущего изучения организации тренировок. Оригинальные демоматериалы требуют методической проверки Полины и не приписываются ей. Их использование ограничено явно включённым режимом DEMO_MODE.

По последнему заданию дальнейшее подключение образовательных источников отложено до публикации среды. Их недоступность не блокирует установку npm, PostgreSQL, миграции, сборку и локальную проверку API.
